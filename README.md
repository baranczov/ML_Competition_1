## Описание проекта

Участие в соревновании Kaggle по прогнозированию досрочного погашения кредитов для "Т-Банка". Задача классификации с целевой переменной `a6_flg` - флаг досрочного погашения в течение 6 месяцев.

**Цель:** Построить модель, которая на этапе одобрения заявки предсказывает вероятность досрочного погашения кредита. Досрочное погашение уменьшает доходность кредита для банка, поэтому точный прогноз позволяет оптимизировать кредитную политику.

**Метрика оценки:** ROC-AUC

**Бейзлайн:** 0.73707

## Результаты

- **Преодолен бейзлайн** соревнования (результат ROC-AUC = 0.74)
- **Реализован ансамбль моделей** CatBoost + LightGBM
- **Учтён временной сдвиг** между тренировочной и тестовой выборками
- **Оптимизирована обработка данных** с высокой долей пропусков
